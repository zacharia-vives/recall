# The faces in this folder

Served from here rather than from Google, on purpose. Recall refuses cloud
text recognition and cloud speech because both would send somebody's hospital
letter to a company's server, and asking Google for a font on every reading is
the same mistake in a smaller coat: it hands over the IP address of a woman
with mild memory loss. Dynamic Google Fonts embedding is also the subject of a
German ruling on precisely that point, so it is not a theoretical objection.

Nothing here is contacted third party, and nothing is downloaded until a skin
actually uses the family.
